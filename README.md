# 🇮🇳 COVID-19 Dashboard – India Analysis (Power BI)

This project is a comprehensive and interactive **Power BI Dashboard** that analyzes the **COVID-19 pandemic trends in India** from 2020 to 2022. It uses official case and population data to uncover insights about multiple waves, recovery patterns, and regional impacts.

---

## 📊 Dashboard Features

- 🦠 **Wave-wise COVID-19 Case Analysis** (2020, 2021, 2022)
- 🧪 **Daily Trends:** New Cases, Recoveries, Deaths
- 📍 **State-wise Comparisons**
- 📈 **Population-adjusted Metrics**
- ⏳ **Time Series Visuals with Slicers**
- 🎨 Visually themed using custom background (`background.png`)
